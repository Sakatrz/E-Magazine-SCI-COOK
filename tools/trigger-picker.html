1. Buka gambar halaman

Klik lalu drag di atas gambar untuk menggambar kotak area trigger (tombol navigasi / teks yang bisa diklik). Bisa gambar berkali-kali untuk beberapa trigger dalam 1 halaman.

Teks yang kepotong ganti baris (misal "termometer" di baris atas, "digital" di baris bawah): gambar 2 kotak terpisah (satu per potongan baris), lalu di kotak kedua pilih "Sama seperti trigger #..." supaya isi popupnya otomatis kembar tanpa isi ulang manual.
Untuk mode "Gambar": klik "Choose File" lalu pilih file PNG popup-nya (yang sudah kamu export dari Figma). Path-nya otomatis dibuat sebagai images/popups/nama-file.png — pastikan file itu memang sudah kamu taruh di folder images/popups/ sebelum ditest di browser (di sini cuma untuk ambil nama filenya & preview, bukan meng-copy filenya).
